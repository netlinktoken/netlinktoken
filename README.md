# 🪩 Netlink (NET)

Welcome to the **official GitHub profile of Netlink**, a Web3 ecosystem built on the **Polygon (PoS)** network.

Netlink combines a digital identity platform (bio link, CV builder, business page) with an embedded crypto wallet — **Netlink Pay** — powered by the **NET** utility token.

## ⚙️ Technology Stack
| Layer | Technology |
|-------|-------------|
| Frontend | Vanilla HTML/JS, Tailwind CSS |
| Hosting | Vercel (serverless functions) |
| Database & Auth | Supabase (PostgreSQL + RLS) |
| Wallet | Sequence WaaS (embedded smart contract wallets) |
| Blockchain | Polygon PoS |
| Swap Aggregator | LI.FI |
